# Firmware ESP32-C3

`Codigo_Terminado_publico.ino` es una copia preparada para publicación: las credenciales Wi-Fi y MQTT fueron sustituidas por marcadores (`TU_WIFI`, `TU_CLAVE_WIFI`, `IP_DEL_BROKER`, etc.). Configurá esos datos en una copia local antes de compilar y cargar el firmware.

No publiques contraseñas, tokens ni direcciones privadas del entorno escolar. El archivo de reparación BH1750 de pruebas no se incluye porque no fue validado como versión funcional.
