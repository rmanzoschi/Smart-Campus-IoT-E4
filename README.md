# Smart Campus IoT — Equipo G4

Repositorio del proyecto escolar Smart Campus IoT – Nodo G4.

## Estructura

- `index.html`: documentación técnica principal (entrada de GitHub Pages).
- `dashboard.html`: dashboard del proyecto.
- `visor3d/`: visor web y modelo 3D del nodo.
- `assets/fotos/`: registro fotográfico del proyecto.
- `planificacion/`: Carta Gantt en Excel y CSV.
- `diagramas/`: esquemas técnicos disponibles.
- `codigo/firmware_esp32/`: reservado para el código fuente definitivo del ESP32-C3.
- `recursos/`: archivos de referencia y desarrollo.

## Publicación

En GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
La página principal se publica desde `index.html`.

## Pendiente de incorporar

- Código fuente definitivo del ESP32-C3, una vez confirmado como versión de entrega.
- Cualquier archivo adicional que el equipo decida publicar.

No colocar contraseñas, PIN de administración, claves Wi-Fi ni credenciales MQTT en este repositorio.
